What contractor websites need

For a contractor, the project portfolio is the sales pitch. A developer or business owner wants to see the work, the scale and the names you've built for. New projects should go up soon after they're finished, and every update should go live without taking the rest of the site down. On page-builder WordPress sites, that means a current backup before any change, every time.
