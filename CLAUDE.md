# elimenti.com

Static HTML/CSS/JS. `elimenti.com` is served by **GitHub Pages** (Jekyll, from `main`) behind Cloudflare DNS. A Cloudflare Pages project also publishes `elimenti.pages.dev` from `main`; `_headers` keeps that copy `noindex`.

## How pages are built

- Each page's `<main id="main"> … </main>` is the source of truth for its content. Edit it directly.
- Everything outside `<main>` (title, meta description, canonical, Open Graph, JSON-LD, nav, breadcrumb, footer) and `sitemap.xml` is generated by `seo/tools/build.py` from its `PAGES` registry. Don't hand-edit those parts; change the registry and run the script.
- FAQPage JSON-LD is generated from visible `.faq-item` blocks (h2/h3 + p), so markup always matches the page.

After any change:
```
python3 seo/tools/build.py          # rebuild head/nav/footer/schema + sitemap
node seo/tools/og.js                # only if an H1 changed or a page was added (needs Playwright)
```

New page: create `<slug>/index.html` containing only its `<main>` block, add a `PAGES` entry (title ≤ 60 chars, description ≤ 155), run both commands, then link it from relevant pages.

## Checks before merging

```
python3 seo/tools/check.py http://127.0.0.1:<port>   # against a local server of the built site
python3 seo/tools/validate_schema.py                 # official Schema Markup Validator
```

## Content rules

- Never mention AI in site copy. Say "custom-coded", never "hand-coded".
- No fabricated reviews, testimonials, stats, awards or `Review`/`AggregateRating` schema. The only testimonial is Bruce Hodes (CMI Teamwork), verbatim.
- Scope is exact: 1 of 1 Car Club and Aamineez Art are builds; Burdi Clothing is targeted edits to an existing site; ABN Construction Group is ongoing care of an existing WordPress site. Never call edit or care clients "builds".
- Public name is "Hashim H." No street address (service-area business).
- No town pages that only swap the town name. New town pages need genuinely distinct content; otherwise add a section to `/chicago-suburbs-web-design/`.

SEO research, the off-site kit and the latest report are in `seo/`.
