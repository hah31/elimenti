## 4. Search Console and Bing Webmaster Tools

### Google Search Console (Domain property, covers every URL)
1. Go to https://search.google.com/search-console → **Add property** → **Domain** → enter `elimenti.com` → Continue.
2. Google shows a TXT record that starts with `google-site-verification=`. Copy the whole value.
3. In Cloudflare: **elimenti.com → DNS → Records → Add record**
   - Type: `TXT`
   - Name: `@`
   - Content: the full `google-site-verification=…` value you copied (no quotes)
   - TTL: `Auto`
   - Save.
4. Back in Search Console, click **Verify**. If it fails, wait 10 minutes and click again.
5. **Sitemaps** → enter `sitemap.xml` → Submit.
6. **URL Inspection** → paste each of these, then **Request indexing**: `https://elimenti.com/`, `/custom-websites/`, `/pricing/`, `/oak-brook-web-design/`, `/hinsdale-web-design/`, `/chicago-suburbs-web-design/`, `/site-care/`, `/guides/squarespace-vs-custom-website/`.

### Bing Webmaster Tools
1. Go to https://www.bing.com/webmasters → sign in → **Import from Google Search Console** (fastest; it brings the verified site and sitemap).
2. If you'd rather verify by DNS: choose **Add your site manually** → enter `https://elimenti.com/` → **DNS verification**. Bing's DNS method is a **CNAME**, not a TXT record. In Cloudflare: Add record → Type `CNAME`, Name = the code Bing shows, Target = the value Bing shows (it's on `verify.bing.com`), **Proxy status: DNS only (grey cloud)**, TTL Auto. Then click Verify.
3. **Sitemaps** → submit `https://elimenti.com/sitemap.xml` (skip if imported).
4. The **AI Performance** report in Bing Webmaster Tools shows how often Copilot and Bing's AI answers cite your pages. Check it monthly.

### Cloudflare settings to check (5 minutes, matters for AI assistants)
- **Security → Bots:** if "Block AI bots" (or AI Crawl Control) is on, set it to allow. From this sandbox, crawler user agents got 200s, but Cloudflare's AI blocking checks verified bot IPs, which can't be tested from outside. If it's on, ChatGPT, Claude and Perplexity can't read the site.
- **Leave "Managed robots.txt" off.** The live robots.txt currently matches the repo's.
- **Cloudflare Pages project:** a Pages project also publishes the site at `elimenti.pages.dev`. The new `_headers` file marks that copy `noindex`, so it's harmless. If you don't use it, delete the project (Workers & Pages → the project → Settings → Delete).
