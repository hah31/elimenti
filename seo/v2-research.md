### Hosting (rule 7), confirmed
`elimenti.com` is GitHub Pages behind Cloudflare: live responses carry `x-github-request-id`, Fastly `x-served-by`/`via: 1.1 varnish` and `server: cloudflare` with `cf-ray`. `_headers` and `_redirects` only affect the Cloudflare Pages copy at `elimenti.pages.dev` (which correctly sends `x-robots-tag: noindex`). Redirects on elimenti.com are therefore meta refresh plus canonical, which Google treats as permanent when the refresh is instant ([Google, Redirects](https://developers.google.com/search/docs/crawling-indexing/301-redirects)).

### Pages not built, and why
- **No new town pages (Phase 3D).** Burr Ridge, Western Springs and Clarendon Hills have thin results, but the study has 0–4 sites per town there (too few to report) and Elimenti has no client work in them. A page would only swap the town name. The hub keeps a distinct section per town; the study's town-level numbers go to the existing Hinsdale and Oak Brook pages instead.
- **Glen Ellyn page merged into `/chicago-suburbs-web-design/`.** The page existed because ABN Construction was described as a Glen Ellyn contractor "on Roosevelt Road". ABN's own site lists 200 W 22nd Street, Lombard, on every page; nothing ties it to Glen Ellyn. Without that, the page had no reason to exist under rule 5. It now redirects (meta refresh + canonical) to a Glen Ellyn section on the hub built on a verifiable fact (the Downtown North Historic District, NRHP 2013). ABN is corrected to Lombard everywhere, including schema.
- **No free website-check tool (Phase 3C).** The PageSpeed Insights API without a key returned HTTP 429 with `quota_limit_value: 0` for Google's shared keyless project on 2026-11-04, and third-party reports describe the same. There are no Google Cloud credentials in this session to create a key. A tool that fails for most visitors would hurt more than help. To build it later: create a browser key restricted to `elimenti.com/*` in Google Cloud Console and the page is a few hours' work.
- **No llms.txt.** Google's guidance still says no special files are needed for AI features. Lighthouse 13.6 (Oct 2026) added an experimental "Agentic browsing" category with an `llms-txt` audit, but it has weight 0, is "not applicable" when the file is absent and only checks the file's format if present. That's a validator, not evidence that any search or assistant product uses the file. Revisit if a search engine documents using it.
- **No case-study before/after screenshots.** Two projects were new sites with nothing before them; two are maintenance of sites that weren't redesigned. The Internet Archive had no snapshots of the relevant Burdi pages and its CDX endpoint wasn't reachable from this session. The case studies use fresh captures of the live work instead, and say what readers can verify.

## B. Verified guidance (rule 6), checked 2026-11-04
- **FAQ rich results are gone from Google.** Deprecation notice May 8, 2026: "This feature will no longer appear in Google Search starting May 7, 2026"; documentation removed June 15, 2026 ([Search Central, FAQPage](https://developers.google.com/search/docs/appearance/structured-data/faqpage)). FAQPage stays only where it mirrors visible text, for Bing and assistants; nothing counts on it.
- **Article markup:** no required properties; "make sure that all the authors that are presented as authors on the web page are also included in markup", as `Person` with a `url` ([Google, Article](https://developers.google.com/search/docs/appearance/structured-data/article)). Every guide has a visible byline linking to /about/ and matching `author` markup.
- **Dataset markup:** still supported, for Dataset Search. Required: `name`, `description` (50–5,000 characters); `distribution.contentUrl` for downloads. `variableMeasured` and `measurementTechnique` are "pending standardization" ([Google, Dataset](https://developers.google.com/search/docs/appearance/structured-data/dataset)).
- **Meta refresh:** "Google Search interprets instant meta refresh redirects as permanent redirects" ([Google, Redirects](https://developers.google.com/search/docs/crawling-indexing/301-redirects)).
- **IndexNow:** bulk POST of `host`, `key`, `urlList` (and `keyLocation` when the key file isn't at the root); 200 = submitted, 202 = received with key validation pending ([IndexNow](https://www.indexnow.org/documentation)).
- **PageSpeed Insights API, keyless:** 429 with `quota_limit_value: 0` (direct test, 2026-11-04).
- **Lighthouse 13.6.0:** mobile categories performance, accessibility, best practices and SEO, plus an experimental agentic-browsing category; `tap-targets` and `font-size` audits no longer exist (`target-size` remains in accessibility), so the study measures small text and sideways scrolling itself.
- **ICANN Transfer Policy:** registrar must provide the transfer code within 5 calendar days; transfers may be refused within 60 days of creation or a previous transfer; 60-day lock after a change of registrant unless the registrar allows an opt-out ([ICANN](https://www.icann.org/resources/pages/transfer-policy-2016-06-01-en)). Registrar blogs report revisions adopted in 2026 that are not yet in force, so the guide tells readers to check current terms.
- **HIPAA:** 45 CFR 164.508(a)(3) (authorization required for marketing) and 160.103 (covered entity, PHI), read from the eCFR API because HHS and eCFR web pages refuse automated requests.
- **sameAs:** no Elimenti profile (GBP, Instagram, LinkedIn, Facebook, Clutch) could be found by search, so `sameAs` stays empty.
