Aamineez Art: portfolio website

Elimenti designed and custom-coded aamineez.art, a portfolio website for Aamineez, an Arabic calligraphy artist. It was a pro bono project, built to turn a link shared in a local group chat into commission inquiries.

At a glance

Client
Aamineez, Arabic calligraphy and alcohol ink artist
Scope
Full build of a one-page portfolio: gallery, about and inquiries. Pro bono.
Built with
HTML, CSS and JavaScript
Status
Live at aamineez.art

The brief

The launch was a single message in a large local group chat. People would tap the link on their phones and decide in a few seconds whether the work was worth asking about. The site had to load fast, show the work first and make asking about a commission effortless.

What we did

  • Put the work first. An image-led gallery with a full-screen viewer, so each piece can be seen up close on a phone.
  • Kept the words short. An about section in the artist's own voice: how the practice started and what the work combines.
  • Removed the friction. One "Inquire on WhatsApp" button with a message already written, so asking about a commission takes one tap.
  • Stayed quiet. A minimal layout that lets the calligraphy carry the page.

The takeaway

When a site's whole job is turning a quick look into a conversation, fewer features win. One gallery, a short about section in the artist's voice and one button that starts the conversation did more than a full site would have.
