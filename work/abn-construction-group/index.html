ABN Construction Group: website care

ABN Construction Group is a general contractor in Lombard, Illinois, building multifamily, office, retail and industrial projects. Elimenti maintains and extends ABN's existing WordPress site under an hourly agreement: keeping it current, adding new sections and making sure nothing breaks along the way.

The business and its customers

ABN describes its work as pre-construction, construction and post-construction, run as a five-step design-build process. Its customers are developers and business owners planning multifamily housing, offices, retail centers and industrial buildings, and its portfolio runs from food service and hospitality to retail, including a Montblanc boutique in Chicago.

For a contractor like that, the website is where a prospective client checks the scale and quality of past work before a first meeting. The portfolio does the selling, so it has to stay current.

The problem

ABN already had a website, built by another firm, and chose to keep it rather than rebuild. What it needed was someone to keep that site current and add to it.

That's harder than it sounds on this kind of build. The site's public code shows two page builders, Elementor and Neuron, plus a slider plugin and an SEO plugin on top of the theme. On a stack like that, a careless edit or an untested update can break a layout on a page nobody was looking at. Care work has to start from knowing how the site is put together.

What we did, and why

  • Learned the build first. A full onboarding pass through the existing theme, both page builders and the plugins before changing anything, so every later edit starts from knowing which tool controls which page.
  • Estimated every task. An hour estimate before each job and an itemized invoice after, so there are no surprises on either side. Hourly care only works when the client can see what each hour buys.
  • Automotive section (in progress). A new section that brings Real Automotive Group into ABN's site as Real Automotive folds into ABN. The section is being built inside the site's existing design, so it reads as part of the same site.

What you can check

The site is live at abnconstruction.com. The platform details above come from its public page code. The Automotive section isn't published yet.

The takeaway

Keeping a site you've already paid for is often the right call. What matters is that whoever edits it learns the build before touching it and quotes each task before starting, so the site keeps working and the bill holds no surprises.
